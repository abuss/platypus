# plat Phase 0 (MVP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `plat`, a ~3–5k-line single-crate Rust terminal editor where edit mode is home and Esc enters a slim selection-first action mode, per the spec.

**Architecture:** Single crate, 8–9 focused modules (`app`, `document`, `undo`, `keymap`, `prompt`, `render`, `input`, `watch`, `main`). Immediate-mode rendering from ropey buffers; keymap is data (`key → Command`) looked up per mode; every tick is poll → decode → Command → mutate → redraw.

**Tech Stack:** Rust (edition 2021, stable), ratatui + crossterm, ropey, `libc` (SIGTSTP only). std for everything else, including file watching (mtime polling).

**Spec:** `docs/superpowers/specs/2026-11-01-plat-phase0-design.md`

## Global Constraints

- Deps limited to: `ratatui`, `crossterm`, `ropey`, `libc` (signal calls only). No async, no worker threads, no other crates.
- UTF-8 only: files that don't decode as UTF-8 refuse to open with a clear error.
- Positions (cursor, selection anchor/head, edits) are ropey **char offsets** (`usize`), never byte offsets.
- Keybindings exactly as the spec's tables (Global Ctrl, Edit mode, Action mode). `Ctrl-\` stays unbound (reserved).
- Soft wrap: out of scope — no-wrap, horizontal scroll follows cursor.
- Single selection per document in Phase 0, stored as `selections: Vec<Selection>`.
- Unit tests live in `#[cfg(test)] mod tests` per module; the one flow test in `tests/flow.rs`.
- Commit after every task's passing step set; conventional commit messages.

## Review Focus

Failure modes the spec implies but no task headline tests exercise — each pinned by a test in the named task:

1. Opening a binary/non-UTF-8 file → clean error message, no panic, no partial buffer (Task 1).
2. Save failure (e.g. EACCES) → error in status bar, buffer stays dirty, nothing lost (Task 1).
3. External mtime change while buffer is dirty → confirm prompt offered, **not** silent reload (Task 10).
4. Render at degenerate sizes: 1-column terminal, empty document, cursor past EOL → clamped, no panic (Task 3).
5. Panic while terminal is in raw mode → terminal restored before the panic prints (Task 11; manual check with exact command, not automatable cheaply).
